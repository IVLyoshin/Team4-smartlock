
# Описание схемы подключения (Wokwi)

## Платформа
В проекте используется микроконтроллер **ESP32-DevKit-C-V4**. В качестве прошивки выбран интерпретатор **MicroPython**, что позволяет разрабатывать логику управления на языке Python.

## Подключенные компоненты
На текущей схеме симулируются и подключены следующие периферийные модули:

1.  **OLED дисплей (SSD1306):** Подключен по интерфейсу **I2C** (пины SDA -> GPIO21, SCL -> GPIO22). Используется для вывода статуса системы, показаний датчиков и меню.
2.  **Сервопривод (Servo):** Управляющий сигнал подан на **GPIO15**. Питание берется от линии 5V. Может использоваться для имитации открытия/закрытия заслонки или замка.
3.  **Матричная клавиатура (Membrane Keypad 4x4):** Подключена по принципу матричного сканирования к пинам **GPIO13, 12, 14, 27 (строки)** и **GPIO26, 25, 33, 32 (столбцы)**. Предназначена для ввода кода, настроек или переключения режимов.
4.  **Светодиоды:**
    *   **Зеленый (LED1):** Анод через резистор 1 кОм на **GPIO2**.
    *   **Красный (LED2):** Анод через резистор 220 Ом на **GPIO5**.
    Катоды обоих светодиодов замкнуты на землю (GND). Служат для индикации состояний (успех/ошибка, работа/остановка).
5.  **Тактовая кнопка (Pushbutton):** Подключена к **GPIO4** и GND. Предполагает использование внутренней подтяжки (pull-up) в коде для обработки нажатия (например, аварийный сброс или подтверждение).

## Используемые интерфейсы
В схеме задействованы следующие типы взаимодействия с периферией:
*   **I2C:** Для управления дисплеем.
*   **GPIO (Цифровой выход):** Для управления сервоприводом (ШИМ-сигнал) и светодиодами.
*   **GPIO (Цифровой вход):** Для опроса матричной клавиатуры (настройка строк как выходов, столбцов как входов) и чтения состояния кнопки.
