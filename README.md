# Team4-smartlock
Разработан учебный прототип с PIN-клавиатурой и сервоприводом, обеспечивающий управление доступом. Функционал включает подсказки на экране, возможность стирания ввода и ограничение попыток.

## Запуск симуляции

Проект полностью симулируется в среде Wokwi.

Wokwi Online (Рекомендуется)
1.  Перейдите на сайт [wokwi.com](https://wokwi.com).
2.  Нажмите "Open Project" и выберите "Open Diagram.json".
3.  Загрузите файл `diagram.json` из данного репозитория, либо скопируйте его содержимое.
4.  Откройте файл `main.ry` (код программы) во встроенном редакторе.
5.  Нажмите кнопку "Start Simulation".
   Или же просто перейдите по ссылке на готовый проект: https://wokwi.com/projects/458860315529663489
